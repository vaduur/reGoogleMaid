# re:GoogleMaid 1.0

Пошаговая настройка китайской ColorOS с сервисами Google. Android 16 / API 36. Проверено на OnePlus Ace 6T PLR110 с ColorOS 16 и штатным лаунчером 16.6.17.

Приложение сохраняет пакет `dev.local.ace6tdiscover`, чтобы обновлять прежнюю утилиту Ace6T Discover без удаления сопряжения и настроек. Название в Android — **re:GoogleMaid**, versionCode 12. Установку следует выполнять обновлением, без предварительного удаления старой утилиты.

## Девять шагов

1. **Подключение.** Локальное сопряжение по шестизначному коду через уведомление. Ключ создаётся на телефоне. Нужны Wi-Fi и включённая беспроводная отладка; на этой ColorOS пункт называется «Отладка по Wi-Fi». Если открывается меню разработчика, выберите этот пункт.
2. **Китайская лента.** Инструкция по отключению Trending news и Recommended services. Ручная отметка отделена от автоматической проверки. При подключённом Discover мастер показывает замену китайской страницы.
3. **Discover.** Проверка настоящей панели в штатном лаунчере, восстановление и ранее настроенное автоматическое наблюдение. Автоматическая процедура доступна только для PLR110 / launcher versionCode 160060017. Она может кратко отключать AppPlatform и перезапускать рабочий стол; есть обычное и резервное восстановление пакета. Показано отдельное подтверждение.
4. **Поиск.** Установка официального ColorGoogle 16.3.0 из встроенного APK, подготовка его доступов и агента. Настройки перенаправления выбираются в самом ColorGoogle.
5. **Нижний жест.** Настройка Circle to Search через ColorGoogle и отдельная отметка физической проверки удержания полоски.
6. **Питание.** Назначение Google ассистентом, настройка службы голосового взаимодействия, выбор действия питания в ColorGoogle. Google может открывать Gemini вместо старого Ассистента.
7. **Приложения.** Каталог 17 Google-приложений с переходами в Play Маркет. Для телефона, SMS, браузера и ассистента используются системные роли; для Gboard — выбор клавиатуры. Контакты, календарь, почта и часы выбираются через обычные системные меню, где это доступно. Калькулятор ColorOS можно отдельно отключить с сохранением данных и вернуть обратно.
8. **Разрешения.** Только заявленные установленным приложением обычные Android-разрешения. Получатель и точный список показаны перед выдачей; при открытии страницы ничего не выдаётся. Files all-files, полноэкранный сигнал Часов и фон Календаря подтверждаются отдельно. При ошибке часть действий могла уже примениться — перечитайте состояние в системных настройках.
9. **Работа в фоне.** Настройка Doze / фоновой работы только для перечисленных приложений и инструкция по автозапуску ColorOS.

Мастер не меняет прошивку, не получает root, не заменяет лаунчер, не очищает данные приложений и отдельно не настраивает облачную синхронизацию. При запуске выполняется только чтение доступных состояний и продолжается уже выбранное владельцем наблюдение Discover; новые действия требуют кнопки и подтверждения.

## Границы

- Это мастер реальных действий и необходимых ручных системных выборов, а не обещание полностью перевести все компоненты ColorOS.
- Камера, системная галерея, DocumentsUI и необходимые хранилища/службы ColorOS сохраняются. Неподдерживаемые Pixel Camera, Recorder и Weather не устанавливаются.
- Встроенная Google-строка под доком без root на этой прошивке не активирована. Отклонённая отдельная полоска не входит в мастер.
- Google Keep не назначается привилегированной ролью NOTES, Google Фото — ролью SYSTEM_GALLERY: ранее они не прошли проверку Android. Обычные доступные действия открываются стандартно.
- Для Discover и восстановления агента нужны работающие локальная отладка и Wi-Fi. Полная перезагрузка и долговременная работа проверены не для всех сценариев; мастер не включает отладку сам после её отключения Android.
- Обычные команды рассчитаны на основной профиль пользователя 0. Рабочие профили и другие модели не проверялись.

## Сборка из исходников

1. Установите JDK 17+, Android SDK Platform 36 и Build Tools 36.1.0. Откройте проект в Android Studio или укажите SDK в `local.properties` (`sdk.dir=...`). Для консоли Java должна быть доступна через JAVA_HOME или PATH.
2. Windows: `gradlew.bat assembleDebug`. Linux/macOS: `sh gradlew assembleDebug`. Первый запуск требует интернета для Gradle/Maven-зависимостей.
3. Результат: `app/build/outputs/apk/debug/app-debug.apk`.

В архиве есть собственные исходники, `third_party/adbclient`, Gradle wrapper, ресурсы, лицензии и соответствующие исходники встроенного ColorGoogle в `upstream/ColorGoogle-16.3.0-source.zip`. Приватный ключ подписи и данные локального сопряжения не распространяются. Для самостоятельной сборки используется стандартный локально создаваемый debug-ключ; такая самостоятельная сборка не обновит установленный APK с другой подписью без отдельной миграции.

## Исходники по назначению

- `MainActivity.java`, `Ui.java`: шаги, оформление, проверки и подтверждения.
- `FixData.java`: каталог, ограниченные сценарии действий и проверка подписи движка.
- `LocalShell.java`: соединение только с этим телефоном, ограничение времени и размера ответа, отдельный маркер окончания каждой команды.
- `DiscoverService.java`, `bootstrap.sh`: ранее проверенный механизм панели и восстановления.
- `DependencyProvider.java`: выдаёт установщику только один встроенный APK, только на чтение.
- `StatusProvider.java`: ограниченная read-only диагностика, защищённая DUMP; не принимает команды, ключи или коды сопряжения.
